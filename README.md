# Katalog Open PO Ayomart

Halaman katalog pre-order figure, merchandise, dan kostum cosplay Ayomart.

- `index.html`: halaman katalog (satu file, tanpa build).
- `data.json`: daftar barang. Diperbarui saat "update katalog" dari sheet Barang PO Ayomart.
- `assets/`: logo dan foto barang.

Tombol **Ikut PO** membuka Google Form pesanan dengan barang dan varian sudah terisi.
Selama `data.json` berisi `"demo": true`, halaman menampilkan banner data contoh.
