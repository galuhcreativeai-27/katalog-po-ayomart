# Katalog Open PO Ayomart

Halaman katalog pre-order Ayomart.

- `index.html`: halaman katalog (satu file, tanpa build).
- `data/barang.json`: daftar barang, diperbarui saat "update katalog" dari sheet Barang PO Ayomart.
- `assets/`: logo, maskot, dan foto barang.

Tombol **Ikut PO** membuka form pesanan dengan barang, varian, dan jumlah sudah terisi.
Barang bertanda `"contoh": true` tampil dengan label CONTOH.
